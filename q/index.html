How to play

You never drag the objects. The objects move because rules tell them how to behave.

  1. Read the goal and inspect the world.
  2. Editable words in a rule are boxed. Change as few as possible.
  3. Press RUN WORLD. The simulation is deterministic for each level.
  4. If the result is wrong, REWIND the world and revise the rule.
